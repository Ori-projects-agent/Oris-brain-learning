# Ori's Brain & Learning (`Oris-brain-learning`)

Core cognitive engine, personality, autonomous self-functions, memory, and personalized learning curator architecture for **Ori Solarium** (`Ori-projects-agent`).

## What's Inside
- `agent/` — Heartbeat loop (`heartbeat.py`), cybernetic drives (`drives.py`), LLM router (`llm_client.py`), situational tool selector (`tool_selector.py`), self-affordance tools (`tools.py`), and Blender workshop (`modeler.py`).
- `config/` — Ori's persona & passions (`persona.json`), curated knowledge domains (`knowledge_repertoire.json`), and runtime settings (`settings.py`).
- `memory/` — Persistent SQLite multi-tier memory (`sqlite_store.py`) and circadian sleep-state reflection (`reflection.py`).
- `services/` — Fact-checking, web research, live weather/space telemetry, GitHub sync, Ollama & Blender runners.
- `docs/` — Cognitive pipeline, archetype spec, master plan, and the **Ori × Astral Archive Personalized Learning Curator Plan**.

> **Note:** Secrets (`.env`) and local runtime databases (`*.db`) are excluded via `.gitignore`.
